# ErrandGo

ErrandGo is a Lagos-first trusted local errands platform connecting customers with verified people who can help with everyday tasks.

## Phase 1

The current build includes the public marketing experience, customer workspace preview, errand creation flow, and responsive visual design system.

## Phase 2

The operations center preview includes marketplace metrics, verification review, live errands, payment attention items, disputes, and audit activity.
