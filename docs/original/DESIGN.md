# ErrandGo Design System
**Version:** 1.0

## Brand Direction
Trustworthy, fast, local and practical. Use green/black/white as the primary palette with restrained accent usage.

## Typography
Use a modern sans-serif such as Inter, Manrope or equivalent. Strong hierarchy: large action headings, readable body text, clear monetary figures.

## Navigation
Mobile: Home | Errands | Messages | Wallet | Profile.
Desktop: sidebar/top navigation with persistent notifications and account controls.

## Key Screens
Landing page; sign up/login; onboarding; customer dashboard; create errand; errand details; Runner marketplace; active job; chat; wallet; verification; ratings; notifications; support/dispute; admin dashboard.

## UX Principles
- Post an errand in under 2 minutes.
- Keep the primary CTA visible.
- Show price and status clearly.
- Never hide fees.
- Use confirmation screens for irreversible actions.
- Provide empty, loading and error states.
- Design for intermittent connectivity.

## Accessibility
Use sufficient contrast, keyboard navigation, descriptive labels, focus states, readable type and non-color-only status indicators.

## Trust UI
Show Runner verification status, rating, completed jobs and clear cancellation/dispute rules before acceptance.
