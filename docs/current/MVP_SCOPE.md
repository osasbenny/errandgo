# ErrandGo MVP Scope Freeze
**Version:** 1.0  
**Status:** Founder Approval Required  
**Date:** 9 October 2026

## Included in MVP V0.1
- Customer authentication/profile.
- Runner onboarding/profile.
- Runner KYC and manual approval.
- Configurable Lagos service zones.
- Create/fund errand.
- Eligible Runner job feed.
- Job acceptance.
- Job lifecycle/status tracking.
- Basic maps/location support.
- Customer ↔ assigned Runner in-app messaging.
- Push notifications.
- Proof/confirmation flow.
- Ratings/reviews.
- Internal payment/earnings ledger.
- Runner payout eligibility/withdrawal workflow.
- Dispute/report flow.
- Admin Command Center.
- Audit logs/basic analytics.
- Staging and production environments.

## Deferred / Phase 2+
- Full dynamic bidding marketplace unless explicitly approved for MVP.
- Advanced AI pricing.
- WhatsApp-first task creation.
- Multi-city automation.
- Corporate accounts/contracts.
- Subscriptions.
- Fleet ownership.
- Complex route optimization.
- Broad home-services marketplace.
- International payments.
- Automated high-risk errands.

## Change Control
After this scope is signed/frozen, any material new feature must be recorded in `DECISIONS.md` and assigned to:
- MVP change,
- Phase 1.1,
- Phase 2,
- or future backlog.

A new idea is not automatically an MVP requirement.
